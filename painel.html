  1. Crie conta grátis em goatcounter.com.
  2. Copie seu código (o início do endereço: SEU-CODE).
  3. No GoatCounter: Username → API → Create key e copie a chave.
  4. Cole as duas abaixo e clique em Salvar.
  5. No index.html do portfólio, troque SEU-CODE no script do contador e publique.
